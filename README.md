# Samuel Lucas | Sallus Intelligence

Site/blog profissional em Next.js para posicionamento em Gestão em Saúde, Dados, Inteligência Artificial, eficiência operacional e oncologia.

## Identidade visual

- Papel: `#F8F5EE`
- Texto: `#1A1915`
- Muted: `#635D50`
- Laranja assinatura: `#DD560E`
- Verde Sallus: `#1FA37A`
- Azul técnico: `#2D5E80`
- Azul-marinho: `#0F2A44`

## Rodar localmente

```bash
npm install
npm run dev
```

## Publicar na Vercel

Importe este repositório na Vercel como projeto Next.js e use o comando padrão `npm run build`.
